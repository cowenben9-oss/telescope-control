Phone / scope sync

The phone is compared with the step count only while the scope is still or tracking. At each Align/Sync the phone's own error is remembered, so the phone only has to be consistent, not exact. Offsets that are too large are flagged, never chased: re-align on a target.

Keep the phone firmly mounted and don't touch the scope while it runs. Altitude uses the phone's gravity sensor and is the accurate one. For azimuth use the full turn: the magnetometer reads the same after exactly one turn even when the motors distort it, so only the small leftover angle is measured. Check that cables can take a full turn first, and point the tube 10–50° up.
